What to verify

  • Arabic highlight travels right-to-left inside a full shaped line; English travels left-to-right.
  • Hook is readable by 1.5 s; the reel makes sense with sound off.
  • No text under platform UI, no black/frozen/empty frames, no invented numbers.
  • Exactly one audio stream; audio muxed once; loudness near −14 LUFS.
  • npm run check reports 0 issues for both projects; npm run doctor is keyless.
  • No API keys, tokens, paid calls, uploads, or publishing. reel-state.json cost stays zero.

Known sandbox limits

  • WhisperX / faster-whisper libraries installed, but weight prefetch failed with TLS EOF to huggingface.co and download.pytorch.org. Use --offline / --from-json here.
  • Auto-Editor's release binary download failed; the default clean stage uses FFmpeg silencedetect + loudnorm.
  • Chromium comes from @sparticuz/chromium plus extracted NSS/NSPR libraries; HyperFrames renders worked without a CDN.
