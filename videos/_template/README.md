# Reel project template

New projects are generated by `npm run reel`; this folder only holds the starting scaffold and the two ignored smoke-test projects.

```bash
# deterministic offline smoke test, no input file and no models
npm run reel -- --lang ar --project videos/my-ar-reel --demo --offline
npm run reel -- --lang en --project videos/my-en-reel --demo --offline

# real voice / recitation
npm run reel -- --lang ar --project videos/my-ar-reel --input /path/to/voice.wav --offline
```

Put user audio in the project's `input/` folder (or pass an absolute `--input`). Generated per-project files — `audio/`, `words.json`, `captions.srt`, `index.html`, `hyperframes.json`, `assets/`, `render.json`, `qa/`, `frames/`, `reel-state.json` — are build artifacts. `videos/_template/*-smoke/` is ignored; the deliverable MP4s live in `out/`.

`videos/quran-reel-ash-sharh/` is the retained reference example for RTL typography, deterministic GSAP timelines, and offline assets. Do not edit it when creating a new reel.

See the root `README.md`, `docs/ARCHITECTURE.md`, and `docs/INSTALL.md` for the full contract. No API keys, no paid calls, no publishing.
